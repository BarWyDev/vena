## Notes

Agent do Code Review (CR) który:
- weryfikuje zgodność zmian z założeniami i konwencjami projektu (CLAUDE.md / AGENTS.md)
- sprawdza czy kod trzyma się najnowszych i najlepszych standardów już obecnych w projekcie (wzorce, biblioteki, styl)
- nie tylko szuka bugów, ale ocenia spójność z całą bazą kodu
